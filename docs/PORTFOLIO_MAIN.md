# 포트폴리오 메인 아키텍처 및 코어 디자인 명세 (PORTFOLIO_MAIN.md)

본 문서는 디지털 아날로그 하이브리드 포트폴리오의 코어 아키텍처와 전체 시스템 명세, 메인 인터랙티브 캔버스의 동작 원리를 기술합니다.

---

## 1. 프로젝트 철학 및 디자인 의도
* **디지털과 아날로그의 조화:** 계산된 현대 웹(Next.js, Canvas) 위에, 불규칙적이고 무작위적인 아날로그적 물리 텍스처(크레용 필터, 종이 질감, 잉크 번짐 효과)를 렌더링하여 따뜻하면서도 세련된 느낌을 제공합니다.
* **사용성(UX)과 감성의 양립:** 고도화된 인터랙션 애니메이션(GSAP)을 적용하여 감성적인 룩앤필을 확보하면서도, 화면 이동(Pan & Zoom), 페이지 전환 시 딜레이와 성능 드랍을 최소화하여 쾌적한 웹 경험을 보장합니다.

---

## 2. 코어 아키텍처 및 라우팅 구조
프로젝트는 단일 Next.js 애플리케이션으로 동작하며, 메인 대시보드(무한 캔버스 노드 맵)와 개별 작업물(Sub-route) 페이지가 유기적으로 연동되는 하이브리드 구조를 가집니다.

* **루트 경로 (`/`):**
  * `app/page.tsx` 및 `app/components/canvas/title/Main.tsx`를 통해 렌더링되는 2D/3D 무한 노드 맵.
  * `react-konva`를 사용하여 노드들이 나뭇가지 형태로 연결된 마인드맵을 인터랙티브하게 표현합니다.
  * 성능 유지를 위해 뷰포트 컬링(Viewport Culling) 및 적응형 렌더링 기법을 적용합니다.
* **작업물 상세 경로 (`/works/[work-id]`):**
  * 각 작업물은 `app/works/[work-id]/page.tsx` 경로에 독자적으로 캡슐화되어 개발됩니다.
  * Next.js의 Code Splitting을 활용하여 메인 캔버스 맵과 작업물 간의 리소스 간섭 및 번들 크기 비대화를 방지합니다.
* **공통 레이아웃 (`app/works/layout.tsx`):**
  * 모든 하위 작업물에 통일된 아날로그 질감 배경(종이 텍스처)과 SVG 디스플레이스먼트 필터(크레용/종이 엣지 노이즈)를 씌워 전체적인 브랜딩 일관성을 제공합니다.
  * 페이지 진입 시 트랜지션 애니메이션을 조율합니다.
* **공통 UI 컴포넌트:**
  * `app/works/components/BackToMapButton.tsx`: 메인 노드 맵으로 언제든지 부드럽게 복귀할 수 있게 하는 화면 좌측 상단의 고정 버튼입니다.

---

## 3. 메인 캔버스 데이터 구조
메인 무한 노드 맵은 `app/components/canvas/title/data.ts` 파일에서 관리하는 방사형 트리 구조를 기반으로 합니다.
* **트리 구조 (`RAW_TREE`):**
  * 각 노드는 고유 ID, 색상, 이미지, 아이콘 유형, 캡션, 설명, 태그 목록 및 연결된 라우트(또는 외부 URL) 속성을 가집니다.
  * 자식 노드 배열(`children`)을 통해 계층 구조를 형성합니다.
* **방사형 배치 (`buildRadialMap`):**
  * 중심 노드(`root`)로부터 깊이(depth)에 따라 크기와 반경(radius)을 조절하여 노드를 방사형으로 자동 배치합니다.
  * GSAP 트랜지션 및 노드 포커스 시의 중심 이동을 수학적 좌표 보간으로 계산합니다.
