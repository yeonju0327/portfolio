# #2 PROMPT (prompt.md)

본 문서는 인스타그램 매거진 'PROMPT' e-book 넘겨보기 작업물 `#2 PROMPT`의 시스템 설계, 인터랙션 구조 및 아날로그 종이 질감 연출 방식을 기술합니다.

---

## 1. 프로젝트 정보
* **공식 라벨 및 프로젝트명:** `#2 PROMPT`
* **작업물 고유 ID:** `prompt`
* **라우트 경로:** `/works/prompt` (`app/works/prompt/page.tsx`)
* **핵심 기술 스택:** Next.js 16 (React 19), GSAP, HTML5 Canvas 2D / CSS 3D Transform, Web Audio API, TypeScript
* **매거진 표준 이미지 해상도:** 1080 × 1350 px (4:5 비율)

---

## 2. 디자인 및 UX 콘셉트
* **디지털 매거진과 아날로그 책장의 결합:**
  * 화면 진입 시 아날로그 따뜻한 우드 텍스처의 **책장 한 칸이 클로즈업**되어 보여집니다.
  * 책장에는 'PROMPT' 매거진 1~5호가 입체적인 그림자와 조명을 받으며 진열되어 있습니다.
  * 새로운 호(Vol.6, Vol.7 등)를 자유롭게 추가할 수 있는 유연한 데이터 구조(`magazines.ts`)로 설계됩니다.
* **책장 → 테이블 화면 이동 트랜지션:**
  * 책장에서 원하는 호를 클릭하면, GSAP 카메라인터랙션 기반으로 화면이 부드럽게 **테이블 위로 줌인/이동**합니다.
  * 선택한 매거진 호가 물리적 테이블 위에 펼쳐질 준비 상태로 놓입니다.
* **실제 종이 넘김 효과 (Paper Page Flip Engine):**
  * 모서리 드래그 및 클릭에 반응하는 정교한 2D/3D 종이 휘어짐(Paper Curl) 및 입체 그림자 연출.
  * 페이지 중앙 책등(Spine)의 잉크 번짐 및 깊이감 있는 수평 그림자, 넘어가는 페이지 하단의 동적 그림자 연출.
  * 종이가 넘어가는 서사적 아날로그 효과음 및 시각적 피드백 제공.

---

## 3. 화면 및 상태 전환 구조 (State Flow)
1. **`bookshelf` 상태 (책장 뷰):**
   * PROMPT 매거진 1~5호 커버 클로즈업 진열.
   * 호별 마우스 호버 시 입체적 부유 애니메이션 및 하이라이트.
   * 클릭 시 선택한 호 ID를 저장하고 `animating-to-table` 상태를 거쳐 `table` 상태로 전환.
2. **`table` 상태 (테이블 뷰 & e-book 리더):**
   * 테이블 위 선택된 매거진 렌더링.
   * 좌상단 "← 책장으로 돌아가기" 버튼을 통해 언제든지 책장 뷰로 원복 가능.
   * 좌상단 "← 지도 맵으로 돌아가기" (`BackToMapButton`)를 통해 메인 노드 맵으로 복귀 가능.
   * 이전/다음 페이지 넘김 컨트롤러 및 모서리 드래그 flip 기능.

---

## 4. 데이터 구조 설계 (Scalable Architecture)
* `app/works/prompt/data/magazines.ts`:
  * 각 매거진 호(Issue) 데이터:
    * `id`: 고유 식별자 (1, 2, 3, ...)
    * `vol`: 호 수 (Vol. 1, Vol. 2, ...)
    * `title`: "PROMPT Vol.N"
    * `subtitle`: 메인 테마 문구
    * `coverImage`: 1080x1350 커버 캔버스/이미지
    * `pages`: 1080x1350 내지 이미지 배열 (`{ id, imageUrl, caption }`)
  * 새로운 호가 추가될 경우 배열에 데이터 객체만 추가하면 책장과 리더에 자동 반영되도록 구성.

---

## 5. 주요 기술 문제 및 해결 방안 (Troubleshooting Plan)
* **1080x1350 고해상도 종이 넘김 프레임 유지:**
  * CSS 3D matrix transform과 캔버스 정밀 종이 곡선 shadow 맵을 결합하여, DOM 리렌더링 없이 60fps 종이 넘김 연출 구현.
* **페이지 전환 간 렌더링 찌그러짐 방지:**
  * exact 4:5 고정 아스펙트 비율 레벨 유지 및 뷰포트 반응형 스케일 래퍼 적용.

---

## 6. 아날로그 감성 포인트
* 우드 질감 테이블 및 책장의 은은한 림 라이트(Rim Lighting)
* 종이가 넘어갈 때 곡면 그림자와 책등 사이의 깊이감 그림자
* 아날로그 찢어진 종이/크레용 텍스처 백그라운드 연동 (`WorksLayout`)
