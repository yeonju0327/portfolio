# #2 PROMPT (prompt.md)

본 문서는 인스타그램 매거진 'PROMPT' e-book 넘겨보기 작업물 `#2 PROMPT`의 미니멀 모노톤 화이트 테이블 연출 명세를 기술합니다.

---

## 1. 프로젝트 정보
* **공식 라벨 및 프로젝트명:** `#2 PROMPT`
* **작업물 고유 ID:** `prompt`
* **라우트 경로:** `/works/prompt` (`app/works/prompt/page.tsx`)
* **핵심 기술 스택:** Next.js 16 (React 19), GSAP, CSS 3D Transform, HTML5 Canvas 2D, Web Audio API, TypeScript
* **매거진 표준 이미지 해상도:** 1080 × 1350 px (4:5 비율)

---

## 2. 디자인 및 UX 콘셉트 (Clean Matte White Monochrome Table View)
* **군더더기 없는 미니멀 화이트 테이블 뷰:**
  * 모든 캡션/안내 텍스트가 소거된 정갈하고 미니멀한 뷰.
  * 눈부심 없는 은은한 매트 화이트 모노톤 샌드 스톤/우드 상판 톤앤매너 (`#EFEFEA` ~ `#D8D7D1`).
* **아치형(Arch Arc) 매거진 배치 연출:**
  * 5개의 PROMPT 매거진(1~5호)이 완만한 곡선 아치(Arch/Fan Arc)를 그리며 수평/수직 회전 오프셋으로 배치됩니다.
* **방향별 표지 스와이프 이탈 및 중앙 확대 트랜지션 (Interactive Transition):**
  * **마우스 호버:** 매거진 각도가 소폭 확대되며 리프트 업(Lift up)되고 섀도우가 깊어집니다.
  * **표지 클릭 시 애니메이션:**
    * 선택한 표지를 기준으로 **좌측 표지들은 화면 왼쪽 밖(`-120vw`)으로 스와이프**되어 이탈합니다.
    * 선택한 표지를 기준으로 **우측 표지들은 화면 오른쪽 밖(`120vw`)으로 스와이프**되어 이탈합니다.
    * 선택된 표지는 `zIndex`가 최상단으로 상승하며 각 표지별 flex 오프셋(`(2 - idx) * 221px`)을 보정하고 클릭 후 호버 배율(1.08)을 즉시 해제(scale 1.0 고정)함과 동시에, **GPU scale 2.15 역산 섀도우(`0 14px 28px`)를 적용하여 확대 완료 시 스크린상에서 e-book 뷰어 그림자(`0 30px 60px`)와 0.1px 및 1% 농도 오차도 없이 1:1 완벽 동기화**시킵니다.
  * **목록 복귀 시 애니메이션:**
    * e-book 뷰에서 "← 매거진 목록으로" 버튼 클릭 시, 복원 시작 시점부터 아치 고유 레이어(`zIndex`)를 부여하여 중앙 표지가 원래 축소 위치로 복귀할 때 스와이프해 들어오는 표지들과 자연스럽게 포개어지도록 유도하고, 이동 완료 시점의 레이어(zIndex) 튐 및 순간이동 현상을 100% 완전 소멸시킵니다.
* **e-book 뷰어 대형화 규격 및 미니멀 테두리 사양:**
  * **대형 화면 1:1 연속 규격 정렬:** e-book 뷰어(`PageFlipReader`)의 기본 규격을 가로 `569.75px` × 세로 `712.19px` (`scale 2.15`, `aspectRatio: 4/5`)로 대폭 확대하고, 메인 표지의 호버 잔상 해제 및 GPU 역산 그림자 조율을 적용해 전환 시 크기 튐, 위치 이동(Teleportation) 및 그림자 깜빡임을 100% 완전 차단합니다.
  * **하단 이동 UI, 책등 제본 선 및 배경 하단 그림자 소거:** 불필요한 하단 이동 조작 바, 매거진 좌측의 책등 제본 셰이딩(`Spine Crease Depth`), 그리고 배경 하단의 긴 소프트 섀도우를 완전 제거하여 극도로 미니멀하고 정갈한 샌드 스톤 모노톤 테마를 유지합니다.
  * **직각 테두리 (Border Radius Removal):** e-book 매거진 본체 및 확대 모달의 모서리 곡률(`borderRadius`)을 `0px`로 처리하여 정갈한 화이트 모노톤 미니멀 직각 뷰를 유지합니다.
