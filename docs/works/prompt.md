# #2 PROMPT (prompt.md)

본 문서는 인스타그램 매거진 'PROMPT' e-book 넘겨보기 작업물 `#2 PROMPT`의 미니멀 모노톤 화이트 테이블 연출 명세를 기술합니다.

---

## 1. 프로젝트 정보
* **공식 라벨 및 프로젝트명:** `#2 PROMPT`
* **작업물 고유 ID:** `prompt`
* **라우트 경로:** `/works/prompt` (`app/works/prompt/page.tsx`)
* **핵심 기술 스택:** Next.js 16 (React 19), GSAP, CSS 3D Transform, HTML5 Canvas 2D, Web Audio API, TypeScript
* **매거진 표준 이미지 해상도:** 1080 × 1350 px (4:5 비율)

---

## 2. 디자인 및 UX 콘셉트 (Clean Matte White Monochrome Table View)
* **군더더기 없는 미니멀 화이트 테이블 뷰:**
  * 모든 캡션/안내 텍스트가 소거된 정갈하고 미니멀한 뷰.
  * 눈부심 없는 은은한 매트 화이트 모노톤 샌드 스톤/우드 상판 톤앤매너 (`#EFEFEA` ~ `#D8D7D1`).
* **아치형(Arch Arc) 매거진 배치 연출:**
  * 5개의 PROMPT 매거진(1~5호)이 완만한 곡선 아치(Arch/Fan Arc)를 그리며 수평/수직 회전 오프셋으로 배치됩니다.
* **인터랙션 피드백:**
  * 마우스 호버 시 매거진 각도가 평평하게 펴지며 솟구쳐 떠오르고(Lift), 소프트 섀도우가 깊어집니다.
  * 매거진 클릭 시 테이블 위 e-book 리더 뷰로 부드럽게 화면 진입합니다.
